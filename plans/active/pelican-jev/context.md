# Context

Python 3.11, Pillow, pytest, Ruff, FFmpeg/libx264, the Codex CLI with saved authentication, and `TYPESAFE_API_KEY` are available. TypeSafe's Jev API returns typed choices, not arbitrary Logo code. The former fixed guide produced recognizable art but gave Jev almost no control; a later fully unguided primitive-by-primitive loop produced a line and repeated turns. Both results are archived under explicit reference filenames in `output/`.

The current trace format is version 3. Each round sends the broad goal and current canvas image/vector state to a Codex sketch proposer. It returns three bounded command batches, which the project validates without executing. Jev receives the goal, current turtle/canvas state, and these three concrete proposals, then chooses one. Only that batch runs. The trace records all proposals, Jev's answer, and every executed pen and movement command; replay makes no model calls. The app contains no hard-coded pelican/bicycle geometry or feature instructions.

The final live drawing has ten Jev decisions and 166 Logo commands. The selected strokes form a bicycle, long-beaked pelican with pouch, pedaling leg, top hat, fish in the pouch and beak, wheel spokes, and handlebar bell. The picture is rough, humorous line art; the torso is less defined than the head and bicycle. Its final frame and an in-progress video frame were inspected. `output/decisions.json` is the exact trace. `output/pelican_on_bicycle.mp4` is 18.6 seconds, 1280×720, 30 fps, H.264/yuv420p, 535,279 bytes.

The first two rounds of this saved example were proposed by the CLI's initial default model. After one proposer timeout, later rounds used `gpt-6-sol`; the code now pins that model for future runs. Jev selected all ten executed batches. A completed trace can be extended with `draw --resume --max-rounds N` when more detail is wanted.
